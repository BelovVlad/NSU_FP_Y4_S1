\chapter{Квантовые газы}

\rsubtitle{Ферми- и бозе-газы}

Будем измерять температуру в энергетических единицах, то есть положим
%
\begin{equation*}
    k_B = 1.
\end{equation*}

Тогда температура $T$, химический потенциал $\mu$, энергия $E$
и одночастичная энергия $\varepsilon$ имеют одинаковую размерность энергии.


% ============================================================
\section{Классический и квантовый газ}
% ============================================================

Переход от классического газа к квантовому связан с тем,
насколько сильно перекрываются волновые пакеты соседних частиц.

Для газа из $N$ частиц в объёме $V$ среднее расстояние между частицами
по порядку величины равно
%
\begin{equation*}
    \Delta l
    \sim
    \left(
        \frac{V}{N}
    \right)^{1/3}.
\end{equation*}

С другой стороны, пространственный размер волнового пакета частицы
связан с неопределённостью импульса:
%
\begin{equation*}
    \Delta x
    \sim
    \frac{\hbar}{\Delta p}.
\end{equation*}

Для нерелятивистского газа характерная энергия частицы имеет порядок
температуры:
%
\begin{equation*}
    T
    \sim
    \frac{p^2}{2m}.
\end{equation*}

Поэтому, с точностью до численного множителя порядка единицы,
%
\begin{equation*}
    p
    \sim
    \sqrt{mT},
\end{equation*}
%
и соответственно
%
\begin{equation*}
    \Delta p
    \sim
    p
    \sim
    \sqrt{mT}.
\end{equation*}

Отсюда характерный размер волнового пакета
%
\begin{equation*}
    \Delta x
    \sim
    \frac{\hbar}{\sqrt{mT}}.
\end{equation*}

Чтобы газ можно было описывать классически, отдельные частицы должны
оставаться хорошо различимыми в пространстве. Для этого необходимо,
чтобы расстояние между ними было гораздо больше характерного размера
волнового пакета:
%
\begin{equation*}
    \Delta l
    \gg
    \Delta x.
\end{equation*}

Следовательно,
%
\begin{equation*}
    \left(
        \frac{V}{N}
    \right)^{1/3}
    \gg
    \frac{\hbar}{\sqrt{mT}}.
\end{equation*}

Возводя это неравенство в квадрат, получаем
%
\begin{equation*}
    \left(
        \frac{V}{N}
    \right)^{2/3}
    \gg
    \frac{\hbar^2}{mT},
\end{equation*}
%
откуда
%
\[
    \rboxed{
        T
        \gg
        \frac{\hbar^2}{m}
        \left(
            \frac{N}{V}
        \right)^{2/3}
    }.
\]

Это условие \rconcept{больцмановского}, то есть классического, газа.

Если оно перестаёт выполняться, волновые пакеты соседних частиц
начинают существенно перекрываться и необходимо учитывать
квантовую статистику.

\begin{rbox}[left=18pt,right=18pt,top=14pt,bottom=10pt]{[]}
    \centering

    \includegraphics[
        width=0.72\linewidth
    ]{image/lecture_01/classical_quantum_gas.png}

    \captionsetup{
        font=footnotesize,
        labelfont=bf,
        skip=5pt
    }

    \captionof{figure}{
        Сравнение классического и квантового газа.
        В классическом пределе размер волнового пакета частицы
        $\Delta x$ значительно меньше среднего расстояния между частицами
        $\Delta l$, тогда как в квантовом газе
        $\Delta x \sim \Delta l$ и волновые пакеты перекрываются.
    }
    \label{fig:classical_quantum_gas}
\end{rbox}


% ============================================================
\section{Статистические ансамбли}
% ============================================================

Прежде чем переходить непосредственно к квантовым газам,
вспомним основные статистические распределения.


% ------------------------------------------------------------
\subsection{Микроканоническое распределение}
% ------------------------------------------------------------

Рассмотрим полностью изолированную систему. Она не обменивается
с внешней средой ни энергией, ни частицами. Для неё фиксированы
%
\begin{equation*}
    E = \mathrm{const},
    \qquad
    V = \mathrm{const},
    \qquad
    N = \mathrm{const}.
\end{equation*}

Теплообмен с внешней средой отсутствует:
%
\begin{equation*}
    Q = 0.
\end{equation*}

\begin{rbox}[left=18pt,right=18pt,top=14pt,bottom=10pt]{[]}
    \centering

    \includegraphics[
        width=0.58\linewidth
    ]{image/lecture_01/microcanonical_system.png}

    \captionsetup{
        font=footnotesize,
        labelfont=bf,
        skip=5pt
    }

    \captionof{figure}{
        Изолированная система в микроканоническом ансамбле.
        Энергия $E$ и объём $V$ фиксированы, а теплоизолированные
        стенки исключают обмен энергией с окружающей средой.
    }
    \label{fig:microcanonical_system}
\end{rbox}

Пусть $\Gamma$ --- \rconcept{статистический вес} макросостояния,
то есть число доступных микросостояний системы.

В микроканоническом ансамбле все допустимые микросостояния
равновероятны, поэтому вероятность каждого из них равна
%
\begin{equation*}
    \rho
    =
    \frac{1}{\Gamma}.
\end{equation*}

Энтропия определяется выражением
%
\begin{equation*}
    S
    =
    -\sum_i
    \rho_i\ln\rho_i.
\end{equation*}

Поскольку все $\Gamma$ состояний имеют одинаковую вероятность
%
\begin{equation*}
    \rho_i
    =
    \frac{1}{\Gamma},
\end{equation*}
%
получаем
%
\begin{align*}
    S
    &=
    -\sum_{i=1}^{\Gamma}
    \frac{1}{\Gamma}
    \ln\frac{1}{\Gamma}
    \\[4pt]
    &=
    -\ln\frac{1}{\Gamma}
    \sum_{i=1}^{\Gamma}
    \frac{1}{\Gamma}.
\end{align*}

Так как
%
\begin{equation*}
    \sum_{i=1}^{\Gamma}
    \frac{1}{\Gamma}
    =
    1,
\end{equation*}
%
то
%
\[
    \rboxed{
        S = \ln\Gamma
    }.
\]

Для системы с постоянным числом частиц основное термодинамическое
соотношение имеет вид
%
\begin{equation*}
    dE
    =
    T\,dS
    -
    p\,dV.
\end{equation*}

При фиксированном объёме
%
\begin{equation*}
    dV = 0,
\end{equation*}
%
поэтому
%
\begin{equation*}
    dE
    =
    T\,dS.
\end{equation*}

Следовательно,
%
\[
    \rboxed{
        \left(
            \frac{\partial S}{\partial E}
        \right)_V
        =
        \frac{1}{T}
    }.
\]


% ------------------------------------------------------------
\subsection{Каноническое распределение}
% ------------------------------------------------------------

Теперь система находится в тепловом контакте с термостатом.

Она может обмениваться с термостатом энергией, поэтому энергия системы
уже не фиксирована. При этом фиксированы
%
\begin{equation*}
    T,
    \qquad
    V,
    \qquad
    N.
\end{equation*}

\begin{rbox}[left=18pt,right=18pt,top=14pt,bottom=10pt]{[]}
    \centering

    \includegraphics[
        width=0.72\linewidth
    ]{image/lecture_01/canonical_ensemble.png}

    \captionsetup{
        font=footnotesize,
        labelfont=bf,
        skip=5pt
    }

    \captionof{figure}{
        Канонический ансамбль.
        Малая система с фиксированными $N$ и $V$
        находится в тепловом контакте с термостатом,
        поддерживающим постоянную температуру $T$.
        Между системой и термостатом возможен обмен энергией.
    }
    \label{fig:canonical_ensemble}
\end{rbox}н 

Вероятность нахождения системы в состоянии $i$ с энергией
$\varepsilon_i$ определяется распределением Гиббса:
%
\begin{equation*}
    \rho_i
    =
    \frac{1}{Z}
    e^{-\varepsilon_i/T}.
\end{equation*}

Здесь
%
\[
    \rboxed{
        Z
        =
        \sum_i
        e^{-\varepsilon_i/T}
    }
\]
%
--- \rconcept{каноническая статистическая сумма}.

Найдём энтропию:
%
\begin{equation*}
    S
    =
    -\sum_i
    \rho_i\ln\rho_i.
\end{equation*}

Подставляя распределение,
%
\begin{equation*}
    S
    =
    -\sum_i
    \rho_i
    \ln
    \left(
        \frac{1}{Z}
        e^{-\varepsilon_i/T}
    \right).
\end{equation*}

Раскрываем логарифм:
%
\begin{equation*}
    \ln
    \left(
        \frac{1}{Z}
        e^{-\varepsilon_i/T}
    \right)
    =
    -\ln Z
    -
    \frac{\varepsilon_i}{T}.
\end{equation*}

Поэтому
%
\begin{align*}
    S
    &=
    -\sum_i
    \rho_i
    \left(
        -\ln Z
        -
        \frac{\varepsilon_i}{T}
    \right)
    \\[4pt]
    &=
    \ln Z
    \sum_i\rho_i
    +
    \frac{1}{T}
    \sum_i\rho_i\varepsilon_i.
\end{align*}

Используем условия
%
\begin{equation*}
    \sum_i\rho_i
    =
    1
\end{equation*}
%
и
%
\begin{equation*}
    E
    =
    \sum_i
    \rho_i\varepsilon_i.
\end{equation*}

Получаем
%
\[
    \rboxed{
        S
        =
        \ln Z
        +
        \frac{E}{T}
    }.
\]

Введём свободную энергию
%
\begin{equation*}
    F
    =
    E-TS.
\end{equation*}

Подставляя выражение для энтропии,
%
\begin{align*}
    F
    &=
    E
    -
    T
    \left(
        \ln Z
        +
        \frac{E}{T}
    \right)
    \\[4pt]
    &=
    E-T\ln Z-E
    \\[4pt]
    &=
    -T\ln Z.
\end{align*}

Таким образом,
%
\[
    \rboxed{
        F
        =
        -T\ln Z
    }.
\]

Полный дифференциал свободной энергии имеет вид
%
\[
    \rboxed{
        dF
        =
        -S\,dT
        -
        p\,dV
        +
        \mu\,dN
    }.
\]


% ------------------------------------------------------------
\subsection{Большое каноническое распределение}
% ------------------------------------------------------------

В большом каноническом ансамбле система может обмениваться
с окружающей средой не только энергией, но и частицами.

Поэтому фиксированными внешними параметрами являются
%
\begin{equation*}
    T,
    \qquad
    V,
    \qquad
    \mu,
\end{equation*}
%
а энергия $E$ и число частиц $N$ могут флуктуировать.

\begin{rbox}[left=18pt,right=18pt,top=14pt,bottom=10pt]{[]}
    \centering

    \includegraphics[
        width=0.72\linewidth
    ]{image/lecture_01/grand_canonical_ensemble.png}

    \captionsetup{
        font=footnotesize,
        labelfont=bf,
        skip=5pt
    }

    \captionof{figure}{
        Большой канонический ансамбль.
        Система находится в контакте с большим резервуаром,
        поддерживающим постоянные температуру $T$ и химический потенциал $\mu$.
        Между системой и резервуаром возможен обмен как энергией,
        так и частицами.
    }
    \label{fig:grand_canonical_ensemble}
\end{rbox}

Вероятность состояния $i$, содержащего $N$ частиц и имеющего энергию
$\varepsilon_i$, равна
%
\begin{equation*}
    P_{i,N}
    =
    \frac{1}{\Xi}
    \exp
    \left(
        -\frac{\varepsilon_i-\mu N}{T}
    \right).
\end{equation*}

Здесь
%
\[
    \rboxed{
        \Xi
        =
        \sum_{i,N}
        \exp
        \left(
            -\frac{\varepsilon_i-\mu N}{T}
        \right)
    }
\]
%
--- \rconcept{большая статистическая сумма}.

Энтропия определяется выражением
%
\begin{equation*}
    S
    =
    -\sum_{i,N}
    P_{i,N}\ln P_{i,N}.
\end{equation*}

Поскольку
%
\begin{equation*}
    \ln P_{i,N}
    =
    -\ln\Xi
    -
    \frac{\varepsilon_i-\mu N}{T},
\end{equation*}
%
получаем
%
\begin{equation*}
    S
    =
    \ln\Xi
    +
    \frac{E-\mu N}{T}.
\end{equation*}

Следовательно,
%
\begin{equation*}
    TS
    =
    T\ln\Xi
    +
    E
    -
    \mu N.
\end{equation*}

Перенося слагаемые,
%
\begin{equation*}
    E
    -
    TS
    -
    \mu N
    =
    -T\ln\Xi.
\end{equation*}

Введём \rconcept{большой термодинамический потенциал}
%
\begin{equation*}
    \Omega
    =
    E
    -
    TS
    -
    \mu N.
\end{equation*}

Тогда
%
\[
    \rboxed{
        \Omega
        =
        -T\ln\Xi
    }.
\]

Его полный дифференциал равен
%
\[
    \rboxed{
        d\Omega
        =
        -S\,dT
        -
        p\,dV
        -
        N\,d\mu
    }.
\]

Свободная энергия определяется как
%
\begin{equation*}
    F
    =
    E-TS,
\end{equation*}
%
поэтому
%
\begin{equation*}
    \Omega
    =
    F-\mu N.
\end{equation*}

Введём также термодинамический потенциал
%
\begin{equation*}
    \Phi
    =
    E
    -
    TS
    +
    pV
    =
    F+pV.
\end{equation*}

Для однородной экстенсивной системы
%
\begin{equation*}
    \Phi
    =
    \mu N.
\end{equation*}

Следовательно,
%
\begin{align*}
    \Omega
    &=
    F-\Phi
    \\[4pt]
    &=
    F-(F+pV)
    \\[4pt]
    &=
    -pV.
\end{align*}

Таким образом,
%
\[
    \rboxed{
        \Omega
        =
        -pV
    }.
\]

\section{Больцмановский и квантовый газы}
% ============================================================


% ------------------------------------------------------------
\subsection{Больцмановский газ}
% ------------------------------------------------------------

Для идеального классического газа сначала удобно рассмотреть
статистическую сумму одной частицы $Z_1$.

Если система содержит $N$ одинаковых невзаимодействующих частиц,
то для неразличимых классических частиц статистическая сумма системы
имеет вид
%
\[
    \rboxed{
        Z
        =
        \frac{Z_1^N}{N!}
    }.
\]

Множитель $1/N!$ устраняет многократный подсчёт состояний,
отличающихся только перестановкой одинаковых частиц.


% ------------------------------------------------------------
\subsection{Фермионы и бозоны}
% ------------------------------------------------------------

Квантовые частицы делятся на два принципиально различных класса:
\rconcept{фермионы} и \rconcept{бозоны}.

Фермионы имеют полуцелый спин:
%
\begin{equation*}
    s
    =
    \frac{1}{2},
    \frac{3}{2},
    \frac{5}{2},
    \ldots
\end{equation*}

Их многочастичная волновая функция антисимметрична относительно
перестановки двух одинаковых частиц.

Из принципа Паули следует, что в одном одночастичном квантовом
состоянии может находиться не более одной частицы:
%
\[
    \rboxed{
        N_i
        =
        0,\;1
    }.
\]

Бозоны имеют целый спин:
%
\begin{equation*}
    s
    =
    0,1,2,\ldots
\end{equation*}

Их многочастичная волновая функция симметрична относительно
перестановки одинаковых частиц.

Число бозонов в одном квантовом состоянии не ограничено:
%
\[
    \rboxed{
        N_i
        =
        0,1,2,3,\ldots
    }.
\]

Именно различие допустимых чисел заполнения приводит к двум
различным квантовым распределениям.


% ============================================================
\section{Распределения Ферми--Дирака и Бозе--Эйнштейна}
% ============================================================

Рассмотрим отдельное одночастичное состояние с энергией
$\varepsilon_i$.

Для краткости введём
%
\begin{equation*}
    x_i
    =
    \frac{\varepsilon_i-\mu}{T}.
\end{equation*}


% ------------------------------------------------------------
\subsection{Распределение Ферми--Дирака}
% ------------------------------------------------------------

Для фермионов в состоянии $i$ может находиться либо ноль,
либо одна частица:
%
\begin{equation*}
    N_i
    =
    0,1.
\end{equation*}

Поэтому вклад этого состояния в большую статистическую сумму равен
%
\begin{equation*}
    \Xi_i
    =
    1+e^{-x_i},
\end{equation*}
%
то есть
%
\[
    \rboxed{
        \Xi_i
        =
        1
        +
        e^{-(\varepsilon_i-\mu)/T}
    }.
\]

Большой термодинамический потенциал одного состояния:
%
\begin{equation*}
    \Omega_i
    =
    -T\ln\Xi_i.
\end{equation*}

Следовательно,
%
\[
    \rboxed{
        \Omega_i
        =
        -T
        \ln
        \left(
            1
            +
            e^{-(\varepsilon_i-\mu)/T}
        \right)
    }.
\]

Среднее число частиц в состоянии определяется через производную
по химическому потенциалу:
%
\begin{equation*}
    N_i
    =
    -
    \left(
        \frac{\partial\Omega_i}{\partial\mu}
    \right)_{T,V}.
\end{equation*}

Вычислим эту производную:
%
\begin{align*}
    N_i
    &=
    T
    \frac{1}{
        1+e^{-(\varepsilon_i-\mu)/T}
    }
    \frac{\partial}{\partial\mu}
    e^{-(\varepsilon_i-\mu)/T}
    \\[4pt]
    &=
    T
    \frac{1}{
        1+e^{-(\varepsilon_i-\mu)/T}
    }
    \frac{1}{T}
    e^{-(\varepsilon_i-\mu)/T}
    \\[4pt]
    &=
    \frac{
        e^{-(\varepsilon_i-\mu)/T}
    }{
        1+e^{-(\varepsilon_i-\mu)/T}
    }.
\end{align*}

Умножая числитель и знаменатель на
$e^{(\varepsilon_i-\mu)/T}$, получаем
%
\[
    \rboxed{
        N_i
        =
        \frac{1}{
            e^{(\varepsilon_i-\mu)/T}+1
        }
    }.
\]

Это \rconcept{распределение Ферми--Дирака}.


% ------------------------------------------------------------
\subsection{Распределение Бозе--Эйнштейна}
% ------------------------------------------------------------

Для бозонов возможны числа заполнения
%
\begin{equation*}
    N_i
    =
    0,1,2,3,\ldots
\end{equation*}

Поэтому
%
\begin{equation*}
    \Xi_i
    =
    1
    +
    e^{-x_i}
    +
    e^{-2x_i}
    +
    e^{-3x_i}
    +
    \ldots
\end{equation*}

Это геометрическая прогрессия со знаменателем
%
\begin{equation*}
    q
    =
    e^{-x_i}.
\end{equation*}

Следовательно,
%
\begin{equation*}
    \Xi_i
    =
    \frac{1}{
        1-e^{-x_i}
    },
\end{equation*}
%
или
%
\[
    \rboxed{
        \Xi_i
        =
        \frac{1}{
            1-e^{-(\varepsilon_i-\mu)/T}
        }
    }.
\]

Большой термодинамический потенциал:
%
\begin{equation*}
    \Omega_i
    =
    -T\ln\Xi_i.
\end{equation*}

Поэтому
%
\begin{align*}
    \Omega_i
    &=
    -T
    \ln
    \frac{1}{
        1-e^{-(\varepsilon_i-\mu)/T}
    }
    \\[4pt]
    &=
    T
    \ln
    \left(
        1-e^{-(\varepsilon_i-\mu)/T}
    \right).
\end{align*}

Таким образом,
%
\[
    \rboxed{
        \Omega_i
        =
        T
        \ln
        \left(
            1-e^{-(\varepsilon_i-\mu)/T}
        \right)
    }.
\]

Среднее число заполнения определяется как
%
\begin{equation*}
    N_i
    =
    -
    \left(
        \frac{\partial\Omega_i}{\partial\mu}
    \right)_{T,V}.
\end{equation*}

В результате
%
\[
    \rboxed{
        N_i
        =
        \frac{1}{
            e^{(\varepsilon_i-\mu)/T}-1
        }
    }.
\]

Это \rconcept{распределение Бозе--Эйнштейна}.


% ------------------------------------------------------------
\subsection{Объединённая запись}
% ------------------------------------------------------------

Обе статистики удобно записывать одной формулой:
%
\[
    \rboxed{
        \Omega_i
        =
        \mp T
        \ln
        \left(
            1
            \pm
            e^{-(\varepsilon_i-\mu)/T}
        \right)
    }.
\]

Соответственно,
%
\[
    \rboxed{
        N_i
        =
        \frac{1}{
            e^{(\varepsilon_i-\mu)/T}\pm1
        }
    }.
\]

Далее будем использовать следующее соглашение о знаках:
%
\begin{equation*}
    \begin{array}{c|c}
        \text{фермионы} & \text{верхний знак},\\
        \text{бозоны}   & \text{нижний знак}.
    \end{array}
\end{equation*}

То есть для фермионов
%
\begin{equation*}
    N_i^{(F)}
    =
    \frac{1}{
        e^{(\varepsilon_i-\mu)/T}+1
    },
\end{equation*}
%
а для бозонов
%
\begin{equation*}
    N_i^{(B)}
    =
    \frac{1}{
        e^{(\varepsilon_i-\mu)/T}-1
    }.
\end{equation*}


% ============================================================
\section{Термодинамика идеального квантового газа}
% ============================================================


% ------------------------------------------------------------
\subsection{Переход от суммы по состояниям к интегралу}
% ------------------------------------------------------------

Полный большой термодинамический потенциал идеального газа
представляет собой сумму вкладов всех одночастичных состояний:
%
\begin{equation*}
    \Omega
    =
    \sum_i
    \Omega_i.
\end{equation*}

Когда уровни расположены достаточно густо, дискретную сумму можно
заменить интегралом по фазовому пространству:
%
\[
    \rboxed{
        \sum_i
        \longrightarrow
        g
        \int
        \frac{
            d^3p\,d^3x
        }{
            (2\pi\hbar)^3
        }
    }.
\]

Здесь $g$ --- кратность вырождения состояния, например число
возможных спиновых состояний.

Для однородного газа
%
\begin{equation*}
    \int d^3x
    =
    V.
\end{equation*}

Поэтому
%
\[
    \rboxed{
        \Omega
        =
        \mp
        TgV
        \int
        \frac{d^3p}{(2\pi\hbar)^3}
        \ln
        \left(
            1
            \pm
            e^{-(\varepsilon-\mu)/T}
        \right)
    }.
\]

Полное число частиц:
%
\begin{equation*}
    N
    =
    \sum_i
    N_i.
\end{equation*}

После перехода к интегралу
%
\[
    \rboxed{
        N
        =
        gV
        \int
        \frac{d^3p}{(2\pi\hbar)^3}
        \frac{1}{
            e^{(\varepsilon-\mu)/T}\pm1
        }
    }.
\]

Полная энергия имеет вид
%
\begin{equation*}
    E
    =
    \sum_i
    \varepsilon_iN_i.
\end{equation*}

Следовательно,
%
\[
    \rboxed{
        E
        =
        gV
        \int
        \frac{d^3p}{(2\pi\hbar)^3}
        \frac{\varepsilon}{
            e^{(\varepsilon-\mu)/T}\pm1
        }
    }.
\]


% ------------------------------------------------------------
\subsection{Нерелятивистский квантовый газ}
% ------------------------------------------------------------

Для свободной нерелятивистской частицы
%
\begin{equation*}
    \varepsilon
    =
    \frac{p^2}{2m}.
\end{equation*}

Отсюда
%
\begin{equation*}
    p
    =
    \sqrt{2m\varepsilon}.
\end{equation*}

Так как распределение изотропно по импульсам,
%
\begin{equation*}
    d^3p
    =
    4\pi p^2\,dp.
\end{equation*}

Преобразуем элемент объёма импульсного пространства
к интегрированию по энергии.

Из
%
\begin{equation*}
    p
    =
    \sqrt{2m\varepsilon}
\end{equation*}
%
следует
%
\begin{equation*}
    dp
    =
    \frac{m}{p}\,d\varepsilon
    =
    \frac{m}{
        \sqrt{2m\varepsilon}
    }
    \,d\varepsilon.
\end{equation*}

Следовательно,
%
\begin{align*}
    p^2dp
    &=
    2m\varepsilon
    \frac{m}{
        \sqrt{2m\varepsilon}
    }
    \,d\varepsilon
    \\[4pt]
    &=
    \frac{(2m)^{3/2}}{2}
    \sqrt{\varepsilon}\,
    d\varepsilon.
\end{align*}

Поэтому
%
\begin{align*}
    d^3p
    &=
    4\pi p^2dp
    \\[4pt]
    &=
    2\pi
    (2m)^{3/2}
    \sqrt{\varepsilon}\,
    d\varepsilon.
\end{align*}

Тогда фазовый объём принимает вид
%
\begin{equation*}
    gV
    \frac{d^3p}{
        (2\pi\hbar)^3
    }
    =
    VA
    \sqrt{\varepsilon}\,
    d\varepsilon,
\end{equation*}
%
где введено обозначение
%
\[
    \rboxed{
        A
        =
        \frac{
            g(2m)^{3/2}
        }{
            (2\pi)^2\hbar^3
        }
    }.
\]

Таким образом, плотность одночастичных состояний для трёхмерного
нерелятивистского газа пропорциональна $\sqrt{\varepsilon}$.

Большой термодинамический потенциал:
%
\[
    \rboxed{
        \Omega
        =
        \mp TVA
        \int_0^\infty
        \sqrt{\varepsilon}\,
        \ln
        \left(
            1
            \pm
            e^{-(\varepsilon-\mu)/T}
        \right)
        d\varepsilon
    }.
\]

Число частиц:
%
\[
    \rboxed{
        N
        =
        VA
        \int_0^\infty
        \frac{
            \sqrt{\varepsilon}\,
            d\varepsilon
        }{
            e^{(\varepsilon-\mu)/T}\pm1
        }
    }.
\]

Энергия:
%
\[
    \rboxed{
        E
        =
        VA
        \int_0^\infty
        \frac{
            \varepsilon^{3/2}\,
            d\varepsilon
        }{
            e^{(\varepsilon-\mu)/T}\pm1
        }
    }.
\]


% ------------------------------------------------------------
\subsection{Связь между давлением и энергией}
% ------------------------------------------------------------

Для однородной системы
%
\begin{equation*}
    \Omega
    =
    -pV.
\end{equation*}

Поэтому для нерелятивистского газа
%
\begin{equation*}
    -pV
    =
    \mp TVA
    \int_0^\infty
    \sqrt{\varepsilon}\,
    \ln
    \left(
        1
        \pm
        e^{-(\varepsilon-\mu)/T}
    \right)
    d\varepsilon.
\end{equation*}

Интегрируем по частям. Положим
%
\begin{equation*}
    u
    =
    \ln
    \left(
        1
        \pm
        e^{-(\varepsilon-\mu)/T}
    \right),
\end{equation*}
%
а
%
\begin{equation*}
    dv
    =
    \sqrt{\varepsilon}\,
    d\varepsilon.
\end{equation*}

Тогда
%
\begin{equation*}
    v
    =
    \frac{2}{3}
    \varepsilon^{3/2}.
\end{equation*}

После интегрирования по частям получаем
%
\begin{align*}
    -pV
    &=
    \left.
        \mp
        TVA
        \frac{2}{3}
        \varepsilon^{3/2}
        \ln
        \left(
            1
            \pm
            e^{-(\varepsilon-\mu)/T}
        \right)
    \right|_0^\infty
    \\[6pt]
    &\quad
    -
    \frac{2}{3}
    VA
    \int_0^\infty
    \frac{
        \varepsilon^{3/2}\,
        d\varepsilon
    }{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{align*}

Граничный член обращается в нуль, поэтому
%
\begin{equation*}
    -pV
    =
    -
    \frac{2}{3}
    VA
    \int_0^\infty
    \frac{
        \varepsilon^{3/2}\,
        d\varepsilon
    }{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{equation*}

Но интеграл в правой части представляет собой энергию $E$:
%
\begin{equation*}
    E
    =
    VA
    \int_0^\infty
    \frac{
        \varepsilon^{3/2}\,
        d\varepsilon
    }{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{equation*}

Следовательно,
%
\begin{equation*}
    -pV
    =
    -\frac{2}{3}E.
\end{equation*}

Итак,
%
\[
    \rboxed{
        pV
        =
        \frac{2}{3}E
    }
\]
%
или
%
\[
    \rboxed{
        p
        =
        \frac{2}{3}
        \frac{E}{V}
    }.
\]

Это соотношение справедливо как для идеального ферми-газа,
так и для идеального бозе-газа с нерелятивистской дисперсией
%
\begin{equation*}
    \varepsilon
    =
    \frac{p^2}{2m}.
\end{equation*}

Если частицы ультрарелятивистские и
%
\begin{equation*}
    \varepsilon
    =
    pc,
\end{equation*}
%
аналогичное вычисление даёт
%
\[
    \rboxed{
        p
        =
        \frac{1}{3}
        \frac{E}{V}
    }.
\]


% ============================================================
\section{Классический больцмановский предел}
% ============================================================

Классическая статистика должна получаться как предельный случай
как распределения Ферми--Дирака, так и распределения Бозе--Эйнштейна.

Условием такого предела является
%
\[
    \rboxed{
        e^{\mu/T}
        \ll
        1
    }.
\]

Введём обозначение
%
\begin{equation*}
    z
    =
    e^{\mu/T}.
\end{equation*}

Тогда
%
\begin{equation*}
    z
    \ll
    1.
\end{equation*}

Число заполнения состояния можно переписать в виде
%
\begin{equation*}
    N(\varepsilon)
    =
    \frac{1}{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{equation*}

Умножая числитель и знаменатель на
$e^{-(\varepsilon-\mu)/T}$, получаем
%
\begin{align*}
    N(\varepsilon)
    &=
    \frac{
        e^{(\mu-\varepsilon)/T}
    }{
        1
        \pm
        e^{(\mu-\varepsilon)/T}
    }
    \\[4pt]
    &=
    \frac{
        ze^{-\varepsilon/T}
    }{
        1
        \pm
        ze^{-\varepsilon/T}
    }.
\end{align*}

Так как $z\ll1$, воспользуемся разложением
%
\begin{equation*}
    \frac{1}{1\pm x}
    =
    1
    \mp
    x
    +
    x^2
    \mp
    \ldots
\end{equation*}

Поэтому
%
\begin{align*}
    N(\varepsilon)
    &=
    ze^{-\varepsilon/T}
    \left(
        1
        \mp
        ze^{-\varepsilon/T}
        +
        \ldots
    \right)
    \\[4pt]
    &\approx
    ze^{-\varepsilon/T}
    \mp
    z^2e^{-2\varepsilon/T}.
\end{align*}

В главном порядке
%
\[
    \rboxed{
        N(\varepsilon)
        \approx
        e^{(\mu-\varepsilon)/T}
    }.
\]

Таким образом, при малых числах заполнения распределения
Ферми--Дирака и Бозе--Эйнштейна переходят в одно и то же
\rconcept{распределение Максвелла--Больцмана}.


% ------------------------------------------------------------
\subsection{Первая квантовая поправка}
% ------------------------------------------------------------

Чтобы получить первую квантовую поправку к классическому газу,
необходимо сохранить следующий член разложения.

Начнём с энергии:
%
\begin{equation*}
    E
    =
    VA
    \int_0^\infty
    \frac{
        \varepsilon^{3/2}\,
        d\varepsilon
    }{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{equation*}

Используя
%
\begin{equation*}
    \frac{1}{
        e^{(\varepsilon-\mu)/T}\pm1
    }
    \approx
    e^{\mu/T}e^{-\varepsilon/T}
    \mp
    e^{2\mu/T}e^{-2\varepsilon/T},
\end{equation*}
%
получаем
%
\begin{align*}
    E
    &=
    VAe^{\mu/T}
    \Bigg[
        \int_0^\infty
        \varepsilon^{3/2}
        e^{-\varepsilon/T}
        d\varepsilon
        \\[4pt]
        &\hspace{3.5cm}
        \mp
        e^{\mu/T}
        \int_0^\infty
        \varepsilon^{3/2}
        e^{-2\varepsilon/T}
        d\varepsilon
    \Bigg].
\end{align*}

Используем стандартный интеграл
%
\begin{equation*}
    \int_0^\infty
    x^{\alpha-1}
    e^{-\beta x}
    dx
    =
    \frac{
        \Gamma(\alpha)
    }{
        \beta^\alpha
    }.
\end{equation*}

Для первого интеграла
%
\begin{equation*}
    \alpha
    =
    \frac{5}{2},
    \qquad
    \beta
    =
    \frac{1}{T},
\end{equation*}
%
поэтому
%
\begin{equation*}
    \int_0^\infty
    \varepsilon^{3/2}
    e^{-\varepsilon/T}
    d\varepsilon
    =
    T^{5/2}
    \Gamma
    \left(
        \frac{5}{2}
    \right).
\end{equation*}

Для второго интеграла
%
\begin{equation*}
    \beta
    =
    \frac{2}{T},
\end{equation*}
%
следовательно,
%
\begin{equation*}
    \int_0^\infty
    \varepsilon^{3/2}
    e^{-2\varepsilon/T}
    d\varepsilon
    =
    \left(
        \frac{T}{2}
    \right)^{5/2}
    \Gamma
    \left(
        \frac{5}{2}
    \right).
\end{equation*}

Таким образом,
%
\[
    \rboxed{
        E
        =
        VAe^{\mu/T}
        T^{5/2}
        \Gamma
        \left(
            \frac{5}{2}
        \right)
        \left[
            1
            \mp
            \frac{
                e^{\mu/T}
            }{
                2^{5/2}
            }
        \right]
    }.
\]

Аналогично для числа частиц:
%
\begin{equation*}
    N
    =
    VA
    \int_0^\infty
    \frac{
        \varepsilon^{1/2}\,
        d\varepsilon
    }{
        e^{(\varepsilon-\mu)/T}\pm1
    }.
\end{equation*}

После такого же разложения
%
\begin{align*}
    N
    &=
    VAe^{\mu/T}
    \Bigg[
        \int_0^\infty
        \varepsilon^{1/2}
        e^{-\varepsilon/T}
        d\varepsilon
        \\[4pt]
        &\hspace{3.5cm}
        \mp
        e^{\mu/T}
        \int_0^\infty
        \varepsilon^{1/2}
        e^{-2\varepsilon/T}
        d\varepsilon
    \Bigg].
\end{align*}

В результате
%
\[
    \rboxed{
        N
        =
        VAe^{\mu/T}
        T^{3/2}
        \Gamma
        \left(
            \frac{3}{2}
        \right)
        \left[
            1
            \mp
            \frac{
                e^{\mu/T}
            }{
                2^{3/2}
            }
        \right]
    }.
\]


% ------------------------------------------------------------
\subsection{Квантовая поправка к уравнению состояния}
% ------------------------------------------------------------

Для нерелятивистского газа
%
\begin{equation*}
    E
    =
    \frac{3}{2}pV.
\end{equation*}

Поэтому
%
\begin{align*}
    \frac{3}{2}pV
    &=
    VAe^{\mu/T}
    T^{5/2}
    \Gamma
    \left(
        \frac{5}{2}
    \right)
    \left[
        1
        \mp
        \frac{
            e^{\mu/T}
        }{
            2^{5/2}
        }
    \right].
\end{align*}

Используем свойство гамма-функции
%
\begin{equation*}
    \Gamma(x+1)
    =
    x\Gamma(x).
\end{equation*}

При $x=3/2$
%
\begin{equation*}
    \Gamma
    \left(
        \frac{5}{2}
    \right)
    =
    \frac{3}{2}
    \Gamma
    \left(
        \frac{3}{2}
    \right).
\end{equation*}

Следовательно,
%
\begin{align*}
    \frac{3}{2}pV
    &=
    \frac{3}{2}
    VAe^{\mu/T}
    T^{5/2}
    \Gamma
    \left(
        \frac{3}{2}
    \right)
    \left[
        1
        \mp
        \frac{
            e^{\mu/T}
        }{
            2^{5/2}
        }
    \right].
\end{align*}

С другой стороны,
%
\begin{equation*}
    NT
    =
    VAe^{\mu/T}
    T^{5/2}
    \Gamma
    \left(
        \frac{3}{2}
    \right)
    \left[
        1
        \mp
        \frac{
            e^{\mu/T}
        }{
            2^{3/2}
        }
    \right].
\end{equation*}

Поэтому
%
\begin{equation*}
    pV
    =
    NT
    \frac{
        1
        \mp
        e^{\mu/T}/2^{5/2}
    }{
        1
        \mp
        e^{\mu/T}/2^{3/2}
    }.
\end{equation*}

При малом $e^{\mu/T}$ используем
%
\begin{equation*}
    \frac{1+a}{1+b}
    \approx
    1+a-b.
\end{equation*}

В результате
%
\[
    \rboxed{
        pV
        \approx
        NT
        \left(
            1
            \pm
            \frac{
                e^{\mu/T}
            }{
                2^{5/2}
            }
        \right)
    }.
\]

Верхний знак относится к ферми-газу, нижний --- к бозе-газу.

Таким образом,
%
\begin{equation*}
    p_F
    >
    p_{\mathrm{Boltzmann}},
\end{equation*}
%
а
%
\begin{equation*}
    p_B
    <
    p_{\mathrm{Boltzmann}}.
\end{equation*}


% ------------------------------------------------------------
\subsection{Условие применимости больцмановской статистики}
% ------------------------------------------------------------

В нулевом порядке по $e^{\mu/T}$
%
\begin{equation*}
    N
    \approx
    VA
    e^{\mu/T}
    T^{3/2}
    \Gamma
    \left(
        \frac{3}{2}
    \right).
\end{equation*}

Следовательно,
%
\begin{equation*}
    e^{\mu/T}
    =
    \frac{
        N/V
    }{
        A
        \Gamma(3/2)
        T^{3/2}
    }.
\end{equation*}

По порядку величины
%
\begin{equation*}
    e^{\mu/T}
    \sim
    \frac{N}{V}
    \left(
        \frac{\hbar^2}{mT}
    \right)^{3/2}.
\end{equation*}

Поэтому условие
%
\begin{equation*}
    e^{\mu/T}
    \ll
    1
\end{equation*}
%
эквивалентно
%
\[
    \rboxed{
        \frac{N}{V}
        \left(
            \frac{\hbar^2}{mT}
        \right)^{3/2}
        \ll
        1
    }.
\]

Возводя обе части в степень $2/3$, получаем
%
\begin{equation*}
    \left(
        \frac{N}{V}
    \right)^{2/3}
    \frac{\hbar^2}{mT}
    \ll
    1.
\end{equation*}

Следовательно,
%
\[
    \rboxed{
        T
        \gg
        \frac{\hbar^2}{m}
        \left(
            \frac{N}{V}
        \right)^{2/3}
    }.
\]

Таким образом, условие, полученное из статистического распределения,
совпадает с условием, найденным ранее из сравнения межчастичного
расстояния с размером волнового пакета.


% ------------------------------------------------------------
\subsection{Первая квантовая поправка через концентрацию}
% ------------------------------------------------------------

В ведущем порядке
%
\begin{equation*}
    e^{\mu/T}
    =
    \frac{N}{V}
    \frac{1}{
        A
        \Gamma(3/2)
        T^{3/2}
    }.
\end{equation*}

После подстановки значения $A$ в уравнение состояния получаем
%
\[
    \rboxed{
        pV
        =
        NT
        \left[
            1
            \pm
            \frac{\pi^{3/2}}{2g}
            \frac{N}{V}
            \left(
                \frac{\hbar^2}{mT}
            \right)^{3/2}
        \right]
    }.
\]

Для ферми-газа берётся верхний знак:
%
\begin{equation*}
    p_F V
    =
    NT
    \left[
        1
        +
        \frac{\pi^{3/2}}{2g}
        \frac{N}{V}
        \left(
            \frac{\hbar^2}{mT}
        \right)^{3/2}
    \right].
\end{equation*}

Для бозе-газа берётся нижний знак:
%
\begin{equation*}
    p_B V
    =
    NT
    \left[
        1
        -
        \frac{\pi^{3/2}}{2g}
        \frac{N}{V}
        \left(
            \frac{\hbar^2}{mT}
        \right)^{3/2}
    \right].
\end{equation*}

Таким образом, принцип Паули приводит к эффективному увеличению
давления ферми-газа по сравнению с классическим газом, тогда как
бозе-статистика приводит к уменьшению давления.

Для обычного газа при комнатных условиях квантовая поправка
чрезвычайно мала и имеет порядок
%
\begin{equation*}
    \sim
    10^{-14}.
\end{equation*}

Поэтому обычные разреженные газы при комнатной температуре
с очень высокой точностью описываются распределением
Максвелла--Больцмана.

    }

    \captionof{figure}{

Смысл больцмановского предела можно ещё раз записать как
%
\[
    \rboxed{
        e^{\mu/T}
        \ll
        1
    }.
\]

Если ввести концентрацию
%
\begin{equation*}
    n
    =
    \frac{N}{V}
\end{equation*}
%
и тепловую длину волны де Бройля по порядку величины
%
\begin{equation*}
    \lambda_T
    \sim
    \frac{\hbar}{\sqrt{mT}},
\end{equation*}
%
то условие классичности принимает вид
%
\[
    \rboxed{
        n\lambda_T^3
        \ll
        1
    }.
\]


% ============================================================
\section{Вырожденный ферми-газ при \texorpdfstring{$T=0$}{T=0}}
% ============================================================

Распределение Ферми--Дирака имеет вид
%
\begin{equation*}
    N_i
    =
    \frac{1}{
        e^{(\varepsilon_i-\mu)/T}+1
    }.
\end{equation*}

Рассмотрим предел
%
\begin{equation*}
    T
    \rightarrow
    0.
\end{equation*}

Если
%
\begin{equation*}
    \varepsilon_i
    >
    \mu,
\end{equation*}
%
то
%
\begin{equation*}
    \frac{
        \varepsilon_i-\mu
    }{
        T
    }
    \rightarrow
    +\infty,
\end{equation*}
%
следовательно,
%
\begin{equation*}
    e^{(\varepsilon_i-\mu)/T}
    \rightarrow
    \infty
\end{equation*}
%
и
%
\begin{equation*}
    N_i
    \rightarrow
    0.
\end{equation*}

Если же
%
\begin{equation*}
    \varepsilon_i
    <
    \mu,
\end{equation*}
%
то
%
\begin{equation*}
    \frac{
        \varepsilon_i-\mu
    }{
        T
    }
    \rightarrow
    -\infty,
\end{equation*}
%
поэтому
%
\begin{equation*}
    e^{(\varepsilon_i-\mu)/T}
    \rightarrow
    0
\end{equation*}
%
и
%
\begin{equation*}
    N_i
    \rightarrow
    1.
\end{equation*}

Таким образом,
%
\[
    \rboxed{
        N_i
        \underset{T\rightarrow0}{\longrightarrow}
        \begin{cases}
            1,
            &
            \varepsilon_i<\mu,
            \\[2mm]
            0,
            &
            \varepsilon_i>\mu.
        \end{cases}
    }
\]

При абсолютном нуле химический потенциал называется
\rconcept{энергией Ферми}:
%
\[
    \rboxed{
        \mu(T=0)
        =
        \varepsilon_F
    }.
\]

Следовательно,
%
\begin{equation*}
    N_i
    =
    \begin{cases}
        1,
        &
        \varepsilon_i<\varepsilon_F,
        \\[2mm]
        0,
        &
        \varepsilon_i>\varepsilon_F.
    \end{cases}
\end{equation*}

Таким образом, при $T=0$ все одночастичные состояния с энергиями
ниже $\varepsilon_F$ заполнены, а все состояния выше
$\varepsilon_F$ пусты. Такое состояние называется
\rconcept{полностью вырожденным ферми-газом}.

\begin{rbox}[left=18pt,right=18pt,top=14pt,bottom=10pt]{[]}
    \centering

    \includegraphics[
        width=0.72\linewidth
    ]{image/lecture_01/fermi_dirac_distribution.png}

    \captionsetup{
        font=footnotesize,
        labelfont=bf,
        skip=5pt
    }

    \captionof{figure}{
        Распределение Ферми--Дирака по одночастичным энергиям.
        При $T=0$ все состояния с $\varepsilon_i<\varepsilon_F$
        заполнены, а состояния с $\varepsilon_i>\varepsilon_F$ пусты.
        При малой конечной температуре резкая граница размывается
        в области энергий шириной порядка $T$ около энергии Ферми
        $\varepsilon_F$.
    }
    \label{fig:fermi_dirac_distribution}
\end{rbox}


% ------------------------------------------------------------
\subsection{Энергия Ферми}
% ------------------------------------------------------------

При $T=0$ все состояния от нулевой энергии до $\varepsilon_F$
заполнены.

Поэтому число частиц равно
%
\begin{equation*}
    N
    =
    AV
    \int_0^{\varepsilon_F}
    \sqrt{\varepsilon}\,
    d\varepsilon.
\end{equation*}

Вычисляем интеграл:
%
\begin{equation*}
    \int_0^{\varepsilon_F}
    \sqrt{\varepsilon}\,
    d\varepsilon
    =
    \frac{2}{3}
    \varepsilon_F^{3/2}.
\end{equation*}

Следовательно,
%
\begin{equation*}
    N
    =
    AV
    \frac{2}{3}
    \varepsilon_F^{3/2}.
\end{equation*}

Отсюда
%
\begin{equation*}
    \frac{N}{V}
    =
    \frac{2A}{3}
    \varepsilon_F^{3/2},
\end{equation*}
%
поэтому
%
\begin{equation*}
    \varepsilon_F^{3/2}
    =
    \frac{3}{2A}
    \frac{N}{V}.
\end{equation*}

Возводя обе части в степень $2/3$, получаем
%
\[
    \rboxed{
        \varepsilon_F
        =
        \left(
            \frac{3}{2A}
            \frac{N}{V}
        \right)^{2/3}
    }.
\]

Для частиц со спином $1/2$
%
\begin{equation*}
    g
    =
    2.
\end{equation*}

Тогда
%
\begin{align*}
    A
    &=
    \frac{
        2(2m)^{3/2}
    }{
        (2\pi)^2\hbar^3
    }
    \\[4pt]
    &=
    \frac{
        (2m)^{3/2}
    }{
        2\pi^2\hbar^3
    }.
\end{align*}

Следовательно,
%
\begin{align*}
    \frac{3}{2A}
    \frac{N}{V}
    &=
    \frac{
        3\pi^2\hbar^3
    }{
        (2m)^{3/2}
    }
    \frac{N}{V}.
\end{align*}

Поэтому
%
\begin{align*}
    \varepsilon_F
    &=
    \left[
        \frac{
            3\pi^2\hbar^3
        }{
            (2m)^{3/2}
        }
        \frac{N}{V}
    \right]^{2/3}
    \\[6pt]
    &=
    \frac{\hbar^2}{2m}
    \left(
        3\pi^2
        \frac{N}{V}
    \right)^{2/3}.
\end{align*}

Таким образом,
%
\[
    \rboxed{
        \varepsilon_F
        =
        \frac{\hbar^2}{2m}
        \left(
            3\pi^2
            \frac{N}{V}
        \right)^{2/3}
    }.
\]

Удобно также ввести \rconcept{импульс Ферми} $p_F$:
%
\begin{equation*}
    \varepsilon_F
    =
    \frac{p_F^2}{2m}.
\end{equation*}

Сравнивая с выражением для энергии Ферми, получаем
%
\[
    \rboxed{
        p_F
        =
        \hbar
        \left(
            3\pi^2
            \frac{N}{V}
        \right)^{1/3}
    }
\]
%
для фермионов со спиновым вырождением $g=2$.

По порядку величины импульс Ферми можно оценить через среднее
расстояние между частицами:
%
\begin{equation*}
    \Delta x \sim \left(\frac{V}{N}\right)^{1/3},
    \qquad
    p_F \sim \frac{\hbar}{\Delta x}.
\end{equation*}


% ------------------------------------------------------------
\subsection{Энергия и давление вырожденного ферми-газа}
% ------------------------------------------------------------

При $T=0$ полная энергия нерелятивистского идеального ферми-газа
равна сумме энергий всех заполненных состояний:
%
\begin{align*}
    E
    &= \sum_i \varepsilon_i N_i
    = AV\int_0^{\varepsilon_F}
        \sqrt{\varepsilon}\,\varepsilon\,d\varepsilon
    \\[4pt]
    &= AV\,\frac{2}{5}\varepsilon_F^{5/2}.
\end{align*}

Используя найденное ранее число частиц
%
\begin{equation*}
    N = AV\,\frac{2}{3}\varepsilon_F^{3/2},
\end{equation*}
%
получаем
%
\begin{equation*}
    E
    = N\varepsilon_F\,\frac{2}{5}\,\frac{3}{2}
    = \frac{3}{5}N\varepsilon_F.
\end{equation*}

Таким образом,
%
\[
    \rboxed{E = \frac{3}{5}N\varepsilon_F},
    \qquad
    \rboxed{\frac{E}{N} = \frac{3}{5}\varepsilon_F}.
\]

Для нерелятивистского идеального газа
%
\begin{equation*}
    \Omega = -PV = -\frac{2}{3}E.
\end{equation*}
%
Следовательно, при $T=0$
%
\[
    \rboxed{P = \frac{2}{5}\frac{N}{V}\varepsilon_F}.
\]

Даже при нулевой температуре энергия и давление газа не обращаются
в нуль: из-за принципа Паули фермионы заполняют различные состояния
вплоть до энергии Ферми. Это давление называют
\rconcept{давлением вырождения}.


% ------------------------------------------------------------
\subsection{Примеры вырожденных ферми-систем}
% ------------------------------------------------------------

Условие сильного вырождения имеет вид $T\ll\varepsilon_F$, если
температура измеряется в энергетических единицах. Для температуры
в кельвинах это условие записывается как
%
\begin{equation*}
    k_B T \ll \varepsilon_F,
    \qquad
    T \ll T_F,
    \qquad
    T_F = \frac{\varepsilon_F}{k_B},
\end{equation*}
%
где $T_F$ --- \rconcept{температура Ферми}.

\begin{enumerate}
    \item \textbf{Металлы.}
    Энергия Ферми электронов имеет порядок электронвольт.
    Соответствующий температурный масштаб велик:
    %
    \begin{equation*}
        \frac{1\,\text{эВ}}{k_B}
        \approx 1{,}16\cdot 10^4\,\text{К}.
    \end{equation*}
    %
    Поэтому при комнатной температуре $T\sim 300\,\text{К}$
    электронный газ сильно вырожден. Даже температуры плавления
    порядка $T_{\text{плав}}\sim 3000\,\text{К}$ могут оставаться
    значительно ниже температуры Ферми.

    \item \textbf{Звёзды.}
    \begin{enumerate}
        \item \textit{Белые карлики.}
        Давление, противостоящее гравитационному сжатию,
        в основном создаётся вырожденным электронным газом:
        %
        \begin{equation*}
            P \approx P_{\text{вырожд. электронного газа}}.
        \end{equation*}

        \item \textit{Нейтронные звёзды.}
        При высокой плотности возможен захват электронов протонами:
        %
        \begin{equation*}
            e^- + p \longrightarrow n + \nu_e.
        \end{equation*}
        %
        Вещество становится богатым нейтронами; существенную роль
        играет давление вырожденной нейтронной жидкости.
        Взаимодействие частиц также существенно, поэтому модель
        идеального ферми-газа здесь даёт лишь качественное описание.
    \end{enumerate}
\end{enumerate}
