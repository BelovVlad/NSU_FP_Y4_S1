# Старый PDF отдельной части

`ФКСВ_Лекции_part1_старый.pdf` — сохранённый прежний `LaTeX/part1.pdf`.
В нём находится материал по взаимодействию частиц с веществом, тогда как
текущий `parts/part1.tex` лекций ФКСВ пустой. Этот PDF не соответствует
текущим исходникам и не является результатом новой сборки.

Файл сохранён без изменения содержимого. Актуальный полный документ —
`../../ФКСВ_Лекции.pdf`; пока в нём только титульная страница,
оглавление и разделительная страница семестра.
