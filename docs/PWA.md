# Устанавливаемое приложение

Интерфейс общий для сайта, PWA и Android WebView. PWA устанавливается через
меню браузера. Android APK собирается отдельным GitHub Actions workflow;
обновление APK поверх приложения сохраняет данные WebView.

Страницы базы, загруженные картинки, шрифты и библиотеки сохраняются при
открытии. Первое открытие материала требует сети. Поиск без сети работает
по уже загруженным частям индекса; недоступные части показываются как
неполные результаты существующим поисковым интерфейсом.

PDF автоматически не скачиваются целиком. В настройках чтения есть кнопка
«Без интернета» (до 150 МБ на файл). Дождитесь сообщения о завершении.
Открыть или удалить материал можно через шестерёнку рядом с «Главная» →
«Сохранённые материалы». «Сохранить все материалы» сохраняет PDF и Notebook,
шрифты, CMaps и ресурсы просмотрщиков из `offline-resources.json`. Число файлов
и примерный объём вычисляются по каталогу; перед началом показывается подтверждение
и доступное место, если браузер поддерживает Storage API. Прогресс показывает
число файлов, байты и текущий документ. Остановка завершает текущий файл;
повторный запуск пропускает сохранённые актуальные версии и повторяет ошибки.
При ошибках не показывается сообщение о сохранении всей библиотеки.
Сохраняется конкретная версия документа: обновлённую версию нужно сохранить
снова. Файлы хранятся в данных сайта, а не в папке Android «Загрузки».
Браузер может освободить кэш при нехватке места; очистка данных сайта также
удаляет сохранённые материалы. Приложение запрашивает устойчивое хранение,
но его предоставление зависит от браузера.

## Заметки и резервные копии

PDF.js 4.10.38 TextLayer обеспечивает нативное выделение и копирование слов,
строк и абзацев. На телефоне используется длительное нажатие. Контекстные кнопки
«Копировать» и «Выделить маркером» сохраняют нативное выделение.
Для сканов без текстового слоя выделение текста недоступно; OCR отсутствует.

«Заметки» включает ручку, полупрозрачный маркер, ластик и комментарии.
Цвет и толщина настраиваются; давление стилуса влияет на толщину штриха.
Undo/Redo работает для добавления, изменения и удаления объектов. Ластик удаляет
целые объекты. Комментарий открывается по значку для чтения, изменения и удаления.
Инструмент «Выделить текст / прокрутка» возвращает управление нативному выделению.
Два пальца масштабируют страницу и отменяют незаконченный штрих.

Аннотации — векторный SVG-слой в координатах PDF. Данные хранятся только на
устройстве в IndexedDB `nsu-pdf-annotations`, отдельно от офлайн-кэша. Они не
отправляются на сервер. Каждое завершённое действие записывается транзакцией.
Сообщение об успехе появляется после её завершения. При ошибке остаются видимые
несохранённые пометки и кнопка повторения; штатная кнопка закрытия ждёт записи.
Принудительное завершение процесса во время записи не гарантирует сохранение
незавершённого действия. Незаконченный штрих при переключении режима отменяется.

Документ определяется стабильным путём, а версия — fingerprint PDF.js. При смене
fingerprint прежние пометки сохраняются отдельно. Просмотрщик предлагает явно
скопировать их в новый PDF. При изменении страниц нужно проверить совпадение.
Все версии включаются в резервную копию.

В настройках доступны «Мои заметки» с переходами к страницам, экспорт JSON,
импорт с проверкой формата и удаление с подтверждением. Импорт объединяет объекты
по ID и времени изменения; более новые записи не заменяются старой копией.
Очистка библиотеки и обновление оболочки не очищают IndexedDB. Очистка данных
браузера/Android-приложения, удаление APK или вытеснение данных браузером могут
удалить файлы и заметки. Регулярно сохраняйте JSON отдельно от приложения.
Синхронизации между устройствами нет.

В APK 1.8 добавлены системные диалоги импорта и сохранения JSON. Старые APK
получают текстовый способ копирования/вставки резервной копии. Системные маркеры
выделения зависят от браузера и версии Android System WebView; сенсорную
эргономику следует дополнительно проверить на физическом устройстве.

Проверка вручную: выделите и скопируйте несколько строк, нарисуйте штрих,
добавьте комментарий, дождитесь сохранения, закройте документ и откройте снова.
Измените масштаб до 250%, включите ленту и поверните устройство. Проверьте
Undo/Redo, стирание одной из двух линий и экспорт → удаление → импорт.
Сохраните библиотеку, закройте вкладки, отключите сеть и откройте PDF и Notebook
через каталог. Удаление загруженного PDF и обновление оболочки должны оставлять
заметки на месте. Произвольные внешние вложения Notebook, сайты, музыка и
комментарии не входят в офлайн-библиотеку. Git LFS pointers разрешаются через
media endpoint GitHub и проверяются как полноценный PDF.

## Разработка

- `manifest.webmanifest` задаёт название, иконки и отдельное окно приложения.
- `app-core.js` — исходник приложения. После изменений запускайте
  `python .github/scripts/build_app_bundle.py`; `app.js` отдельно не редактируйте.
  `app.css` содержит общие стили настроек.
- `annotations-store.js` обслуживает транзакции и резервные копии;
  `pdfjs/notes.js` и `notes.css` — векторный слой и интерфейс. Canvas в ленте
  виртуализируются; записи аннотаций живут независимо от DOM. TextLayer и worker
  используют одну закреплённую версию PDF.js.
- `offline-resources.json` перечисляет ресурсы PDF.js/MathJax/Notebook.
  При обновлении библиотек обновите его вместе с URL в просмотрщиках.
  Подготовка ресурсов проверяется до сообщения об успешном сохранении.
- `sw.js` обслуживает офлайн-кэш в пределах этого сайта. Комментарии,
  внешние сайты и музыка не кэшируются.
- HTML и каталог проверяются по сети; HTML берётся из кэша при сетевой ошибке.
  Версионированные материалы и закреплённые
  версии CDN-библиотек берутся из кэша без повторного запроса.
- Для PDF поддерживаются диапазоны `Range`, включая суффиксы и ответ 416.
  Частичные сетевые ответы не сохраняются как полный документ.
- При изменении оболочки увеличивайте `SHELL_VERSION` в `sw.js` и обновляйте
  пути `CORE`, если изменились версии ресурсов. Новая оболочка устанавливается
  только после успешной загрузки всех обязательных файлов. Обновление
  активируется без принудительной перезагрузки открытого документа; материалы
  и IndexedDB переживают смену версии оболочки. Новый материал записывается
  до удаления старой версии.
- Нужен HTTPS либо localhost. Локальный HTTP-сервер должен отдавать HTML без
  Jekyll front matter (`---` в начале `index.html`); GitHub Pages убирает его
  при публикации. Открытие HTML через `file://` не поддерживает service worker.

Проверки: `python -m unittest discover -s tests -v`. Полная проверка с настоящими
CDN-библиотеками: `NSU_REAL_PDFJS=1 python tests/check_pwa_offline.py`. Она закрывает страницы,
отключает сеть и открывает PDF и формулы заново, сохраняет мобильные скриншоты
в `build/pwa/`. Установку на физическом Android проверяют после публикации.
