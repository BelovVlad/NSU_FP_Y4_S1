# Overseer: материалы для переноса рендера на сайт

Источник: `C:\Users\bjise\Downloads\site\RWLD_copy`.
Извлечение: 26 сентября 2026. Исходная папка игры использовалась только для чтения.

Это отдельный рабочий набор: декомпилированный код, оригинальные шейдеры,
текстуры, спрайты и сведения об их происхождении. Это ещё не браузерный компонент
и не автономно компилируемый Unity-проект.

## С чего начинать

1. `code/render/OverseerGraphics.cs`: внешний вид, геометрия тела, глаз, нити,
   взгляд, свечение, цвет, раскрывающаяся голографическая конструкция.
2. `code/render/CoralBrain.Mycelium.cs`: движение и построение нитей.
3. `shaders/OverseerZip.shader`, `FlatLight.shader`, `Hologram.shader`:
   визуальные эффекты тела, свечения и голограмм.
4. `sprites/rainWorld/Circle20.png`, `pixel.png` и `textures/Futile_White.png`:
   базовые графические элементы.
5. `PORTING-NOTES.md`: связи между кодом, ресурсами и будущими событиями страницы.

`Futile.CreateDefaultAtlases()`. В игре она создаётся при запуске; фильтрация
Bilinear, режим Clamp. Все остальные PNG — копии или декодированные игровые ресурсы.

## Происхождение и проверка

- `copied-files.json`: пути источников и SHA256 побайтово скопированных файлов.
- `extracted-assets.json`: Unity path ID и источник извлечённых атласов.
- `sprites.json`: для каждого спрайта — атлас, исходная рамка, размеры, поля,
  ссылки на C#-файлы; семейства key/button выбраны также по динамическим именам.
- `exported-types.json`: список 27 извлечённых классов/интерфейсов верхнего уровня;
  вложенные классы сохранены внутри них.
- `asset-inventory.json`: список текстур, TextAsset и Sprite в проверенных
  `.assets` и шести Addressables bundle-файлах.
- `checksums.sha256`: контрольные суммы материалов результата, исключая инструменты.
- `verification.json`: итоги проверки копий, PNG и базовых спрайтов.

Сохраняются отдельно базовый `str_proj.png` и вариант Remix: активный вариант
в игре зависит от включённых модов. Атласы взяты из `resources.assets`;
текстурные данные декодированы из его ресурсов, без изменения оригиналов.

## Границы извлечения

Основные спрайты живого Overseer, нити, эффекты, символы подсказок и изображения
проекций выделены. 23 имени изображений дополнительной сцены `GateScene`
(`moon1A`, `otherSlugcat1A` и другие) не найдены в просмотренных ресурсах и
именах отдельных файлов. Полный список: `unresolved-assets.json`.
Они не требуются для тела и глаза Overseer; код сцены сохранён для справки.

Игровые классы зависят от Unity, комнаты, камеры, палитры, физики и других классов
игры. Эти зависимости не замещены и не превращены в автономный движок.
`UnityCG.cginc` — стандартный include Unity, отсутствует среди исходников этой
копии игры. Шейдеры предстоит адаптировать к GLSL/WebGL, а окружение комнаты —
к координатам страницы. Визуальная идентичность ещё не проверялась запуском рендера.

## Повторное извлечение

Инструменты: ILSpy 7.2.1.6856, Python 3.11.9, UnityPy 1.25.3.
Они находятся в `tools` полной рабочей папки, без установки в игру.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\extract-code.ps1
.\tools\python\python.exe .\inspect-assets.py
.\tools\python\python.exe .\extract-assets.py
.\tools\python\python.exe .\verify-and-package.py
```

Скрипты извлечения читают путь игры, указанный в начале файла / параметре
`GameRoot`; результаты пишут только рядом с собой. C# восстановлен ILSpy из
DLL, поэтому имена локальных переменных и форматирование могут отличаться от
оригинального исходного проекта.
