# Ориентиры для браузерного рендера

## Тело и глаз

Главный файл — `code/render/OverseerGraphics.cs`.

- `InitiateSprites`: два длинных меша с `OverseerZip`, четыре спрайта `Circle20`,
  `pixel` для зрачка, `Futile_White` с `FlatLight`, меши нитей.
- `segments = 10`: число сегментов тела по умолчанию.
- `DrawPosOfSegment`: форма тела через кривую Безье между головой и корнем.
- `RadOfSegment`, `ExtensionOfSegment`, `ColorOfSegment`: профиль, раскрытие,
  цвет сегментов. Сохранять формулы при переносе.
- `UpdateDrawPositions`: интерполяция положения головы, корня и взгляда.
- `DrawSprites`: координаты, масштаб, цвет, прозрачность и геометрия каждого слоя.
- `AddToContainer`: порядок слоёв `Items`, `Foreground`, `HUD2` и другие
  условия игры. Для браузера потребуется свой порядок отрисовки.
- `MainColor`: цвет зависит от `ownerIterator`, режима и дополнений.
  Для `ownerIterator == 1` код задаёт RGB `(1, 0.8, 0.3)`.
- `ApplyPalette`: цвет зависит также от палитры комнаты; на сайте его нужно
  задавать явно, чтобы фон страницы не менял образ непредсказуемо.

Вложенный `HologramMatrix` содержит геометрию раскрывающейся конструкции и её
вращение. `SafariCursor` относится к отдельному игровому режиму.

## Нити и движение

`CoralBrain.Mycelium` обновляет цепочки точек и строит длинный треугольный меш.
`OverseerGraphics` создаёт несколько нитей, управляет их размещением и цветом.
`CoralNeuronSystem` сохранён как справочная зависимость взаимодействия с комнатой.

`Overseer` хранит `rootPos`, `rootDir`, `extended`, положение головы и режимы;
`OverseerAI` — `lookAt`, `CosmeticLookAt`, `LensUpdate` и выбор позиции.
`timeStacker` интерполирует предыдущий и текущий шаг состояния: нельзя просто
подменить его абсолютным временем браузера.

Для будущего компонента предлагаются входы: позиция головы, точка прикрепления,
направление корня, цель взгляда, размер, цвет, степень появления и состояние
голограммы. Это проектные ориентиры, новый API пока не реализован.

## Шейдеры

| Шейдер | Назначение |
|---|---|
| `OverseerZip` | Меш тела и эффект перемещения, шумовая маска видимости |
| `FlatLight` | Мягкое свечение |
| `Hologram` | Линии/символы с мерцанием и искажением |
| `HologramImage` | Проекция изображений, панорамирование, шум и выбор кадра |
| `LightSource` | Дополнительный свет голограммы |
| `Basic` | В том числе второй слой актёров GateScene |
| `Bloom` | Упоминается при построении голограммы |
| `HologramBehindTerrain` | Родственный шейдер сохранён для контекста; прямое использование основным телом не подтверждено |

`_NoiseTex2`, `_RAIN`, `_screenSize`, `_spriteRect` участвуют в эффектах.
`_RAIN` нельзя без проверки подставить как секунды: нужно сохранить скорость
анимации. Часть шейдеров зависит от экрана, палитры, terrain/ripple-масок и
`_GrabTexture`; в браузере эти входы нужно явно заменить или воспроизвести.
Локальные include-файлы скопированы рекурсивно, стандартный `UnityCG.cginc`
в наборе отсутствует. Шейдеры сохранены без редактирования.

## Текстуры и голограммы

Отдельные PNG спрайтов восстановлены до `sourceSize`, с учётом
`spriteSourceSize`; при использовании полного атласа следует опираться на
`sprites.json`, чтобы не применить поля дважды. Координаты рамок в JSON идут
от верхнего левого угла; преобразование в UV видно в `FAtlas.LoadAtlasData`.

`Futile_White` создаётся в runtime и имеет размер 16×16.
`noise.png` и `noise2.png` скопированы из `StreamingAssets/palettes`.
Проекции `STR_PROJ`, `RND_PROJ`, `ADS_PROJ`, `MOONAI_PROJ` и вариант Saint
сохранены отдельными файлами; `HologramImage` выбирает изображение в сетке 5×5.

`OverseerHologram` содержит стрелки, символы, указатели на объект/существо и
световые части. `OverseerCommunicationModule` показывает, как выбирается
повод для подсказки. Для сайта аналогом цели может стать DOM-элемент: его
координаты передаются во взгляд и указатель, а содержимое определяет символ
или текст. Это будущая интеграция; чтение страницы в наборе не реализовано.
