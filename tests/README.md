# Проверки сайта

Particle Explorer: `python -m unittest discover -s tests -p test_particles_browser.py -v`
проверяет режимы, вложенные семейства, поиск, связи, мобильные жесты и офлайн-кэш.
`node --test tests/particles-layout.test.cjs` проверяет общую сетку без пересечений, полосы подписей и непрерывные маршруты по рёбрам сот
на 200 частицах (49 исходных + 151 добавленная) и синтетическом каталоге из 800 состояний, включая
неравномерное расширение отдельных семейств. Справочные данные не изменяются.

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
```

Проверка настоящих физических справочников с MathJax и KaTeX (нужен доступ к CDN):

```sh
python tests/check_physics_rendering.py
```

Она проверяет формулы в обоих движках, строчный и блочный режимы, ширину страницы
при 320, 390 и 1440 px и масштабах 80–150%. Скриншоты и отчёт сохраняются в
`build/physics-typography/`. Отдельный тест сверяет все 44 строки СИ и 42 строки
СГС из исходной таблицы констант с текущими численными значениями.

Тесты создают временный сайт и синтетические PDF. Учебные материалы не изменяются.
PWA-проверки запускают настоящий service worker: проверяют офлайн-оболочку,
версии материалов, явное сохранение PDF, диапазоны байтов и удаление файлов.
В остальных тестах service worker отключён для воспроизводимости сетевых сбоев.
Дополнительная проверка настоящих PDF.js и MathJax с последующим отключением
сети: `python tests/check_pwa_offline.py` (мобильные скриншоты — `build/pwa/`).
Проверяются восстановление поиска после сетевых ошибок, смена запроса, повторное
использование PDF-просмотрщика, номера страниц, восстановление после ошибки
отрисовки, разрешение canvas и загрузка настроек комментариев.

По умолчанию PDF.js заменён небольшой тестовой реализацией: проверки работают
без доступа к CDN и могут воспроизводить ошибки отрисовки. Для дополнительной
проверки с настоящим PDF.js задайте `NSU_REAL_PDFJS=1` — потребуется доступ к CDN.
Тест искусственного сбоя отрисовки в этом режиме пропускается.

Аннотации и офлайн-библиотека: `python -m unittest discover -s tests -p test_annotations.py -v`.
Проверяются сохранение в IndexedDB, геометрия после масштабирования, Undo/Redo,
ластик, комментарии, резервные копии и восстановление прежней версии документа,
iframe/fullscreen, ошибка записи, два касания, виртуализация 200 страниц,
сохранность заметок при обновлении оболочки и очистке материалов, остановка и
продолжение загрузки PDF/Notebook. Макеты проверяются на 320, 390, 768 и 1440 px.
Дополнительно проверяются сенсорные планшеты 820/1024/1366 px, ввод стилусом
с давлением и касанием ладони, реальные touch-жесты через CDP (перемещение,
pinch и последующее рисование), единый Undo ластика и штриха между страницами.
Проверка ленты также контролирует сохранение DOM уже нарисованных линий во
время следующего штриха и откладывание перерисовки активной страницы.
Для Pencil проверяются потеря захвата указателя, сохранение штриха при
`pointercancel`, точное завершение линии с давлением, ладонь до касания пера,
резервный ввод через `Touch.touchType=stylus` / `force` и отсутствие двойных
штрихов при совместных Pointer/Touch Events. На планшете проверяется компактная
панель, скрытие при прокрутке вниз, возврат вверх и неизменность области PDF.
Safari/WebKit: `python -m playwright install webkit`, затем переменная
`PLAYWRIGHT_BROWSER=webkit`. Тест с CDP требует Chromium/Edge; Pencil-сценарии
`test_mobile_pencil_capture_loss_endpoint_and_resting_finger`,
`test_mobile_safari_pencil_touch_fallback_and_no_duplicate_ink` и
`test_mobile_tablet_chrome_hides_without_moving_document` работают в WebKit.
Физический Apple Pencil эти проверки не эмулируют.
`check_pwa_offline.py` закрывает все вкладки перед повторным офлайн-запуском и
проверяет PDF с аннотацией и ранее не открывавшийся Notebook с формулами.

На Windows можно использовать установленный Edge без загрузки Chromium:

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
python -m unittest discover -s tests -v
```
