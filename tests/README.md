# Проверки сайта

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
```

Проверка настоящих физических справочников с MathJax и KaTeX (нужен доступ к CDN):

```sh
python tests/check_physics_rendering.py
```

Она проверяет формулы в обоих движках, строчный и блочный режимы, ширину страницы
при 320, 390 и 1440 px и масштабах 80–150%. Скриншоты и отчёт сохраняются в
`build/physics-typography/`. Отдельный тест сверяет все 44 строки СИ и 42 строки
СГС из исходной таблицы констант с текущими численными значениями.

Тесты создают временный сайт и синтетические PDF. Учебные материалы не изменяются.
PWA-проверки запускают настоящий service worker: проверяют офлайн-оболочку,
версии материалов, явное сохранение PDF, диапазоны байтов и удаление файлов.
В остальных тестах service worker отключён для воспроизводимости сетевых сбоев.
Дополнительная проверка настоящих PDF.js и MathJax с последующим отключением
сети: `python tests/check_pwa_offline.py` (мобильные скриншоты — `build/pwa/`).
Проверяются восстановление поиска после сетевых ошибок, смена запроса, повторное
использование PDF-просмотрщика, номера страниц, восстановление после ошибки
отрисовки, разрешение canvas и загрузка настроек комментариев.

По умолчанию PDF.js заменён небольшой тестовой реализацией: проверки работают
без доступа к CDN и могут воспроизводить ошибки отрисовки. Для дополнительной
проверки с настоящим PDF.js задайте `NSU_REAL_PDFJS=1` — потребуется доступ к CDN.
Тест искусственного сбоя отрисовки в этом режиме пропускается.

На Windows можно использовать установленный Edge без загрузки Chromium:

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
python -m unittest discover -s tests -v
```
