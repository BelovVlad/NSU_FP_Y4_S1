# Перенос счётчика кармы

## Место на сайте

Сохранённое требование: секретный раздел открывается двойным тапом;
блок кармы редактора размещается после «Состояние конспектов» и до блоков
«Статистика» и «Сегодня». Ни разметка, ни обработчик двойного тапа на данном
этапе не менялись. Формула начисления кармы, её хранение и привязка к редактору
пока не определены. Уровни 1–10 — требование к визуальному диапазону.

## Два источника поведения

`HUD.KarmaMeter.cs`: компактный индикатор, изменение масштаба/прозрачности,
свечение, предупреждения и анимация reinforcement. Удобная основа для блока.
`Menu.KarmaLadder.cs`: вертикальное колесо/лестница, переходы между уровнями,
кольца, вспышки, защита кармы и расширение максимума.

В `KarmaLadder` вложенный `KarmaSymbol` отвечает за отдельный знак и его кольцо.
`GoToKarma` запускает переход; `Update`, `NewPhase`, `GrafUpdate` управляют
состояниями и отрисовкой. Сохранены фазы Resting, Deselecting, MovingA, MovingB,
Settling, Bump, CappedMovement, CapBump, ReinforceSave.

`HUD.FadeCircle` и `HUD.HUDCircle` дают круговые эффекты. `MoreSlugcats.KarmaVectorX`
сохранён как дополнительный процедурный символ X; обычный десятый уровень уже
есть в `karma9-9` и не требует этого класса.

Счётчики в Update измеряются шагами игровой логики. При переносе на
requestAnimationFrame нужна отдельная шкала времени, иначе длительности
начнут зависеть от частоты экрана. `timeStacker` интерполирует состояния;
он не является абсолютным временем. Случайное мерцание и easing сохранены
в коде, без попытки заменить их заранее нарисованными кадрами.

## Связь анимации со звуком

| Событие/момент | Игровой SoundID / сэмпл |
|---|---|
| Снятие выделения | MENU_Karma_Ladder_Deselect / karmaFuzz |
| Начало движения | MENU_Karma_Ladder_Start_Moving / karmaWheelC_1…4 |
| Движение | MENU_Karma_Ladder_Movement_LOOP / karmaWheelLow |
| Повышение, удар | MENU_Karma_Ladder_Increase_Bump / karmaRiseA + UIWoodHit |
| Верхний предел | MENU_Karma_Ladder_Hit_Upper_Cap / capBell2 |
| Защита, захват/натяжение | Reinforce_Save_Grab, Reinforce_Save_Pull / UIWood5 |
| Рассеивание защиты A | Reinforcement_Dissipate_A / karmaFuzz2 |
| HUD: мерцание / удар защиты | HUD_Karma_Reinforce_Flicker / karmaFuzz2; Reinforce_Bump / UIWood5 |

Точные параметры в `sounds.json`. Сохраняются отдельно параметры события и
сэмпла; при PLAYALL все перечисленные сэмплы звучат вместе. Нумерованные
файлы `_1`…`_4` — варианты одного звука, а не четыре последовательных этапа.
Громкость также зависит от общих настроек загрузчика/игры и аргументов
PlaySound; смотреть `SoundLoader.cs` и место вызова. В preview звуки играют
как отдельные исходные записи, без игрового микширования.

`sounds.json` содержит слои base и mergedmods как справочные версии. Не нужно
воспроизводить их одновременно; для будущего компонента выбирается одна
конфигурация. Не настроенные события и отсутствующие сэмплы перечислены
в `unresolved.json`, им не назначены выдуманные замены.

Для браузера включение звука следует привязать к жесту пользователя, например
двойному тапу открытия раздела; предусмотреть выключение звука. Это ориентир
будущей реализации, текущий набор только хранит ресурсы.

## Графические входы

Пять шейдеров и локальные include сохранены неизменными. VectorCircle и
VectorCircleFadable кодируют параметры окружности через цвет/прозрачность;
это не обычное окрашивание картинки. FlatLight создаёт свечение, LocalBloom —
локальный эффект вспышки. Цвет, фон, палитра и размеры экрана в игре задаются
окружением: при переносе эти значения нужно сделать явными.

Для уровней сайта можно начинать с `karma-levels.json` (cap=9); оригинальные
варианты при других cap сохранены. Отдельные PNG уже имеют прозрачные поля;
при отрисовке не добавлять atlas offset второй раз.
